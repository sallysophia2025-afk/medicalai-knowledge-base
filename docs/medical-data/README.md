# Medical Data

Medical data provides the foundation for developing, evaluating, and monitoring Medical AI systems.

## Data Types

- Electronic Health Records
- Clinical Data
- Medical Imaging Data
- Clinical Text
- Biomedical Data
- Genomic Data
- Physiological Data
- Wearable Data
- Patient-Generated Health Data

## Data Topics

- Data preprocessing
- Data quality
- Data annotation
- Missing data
- Data leakage
- Class imbalance
- Dataset bias
- Dataset shift
- Distribution shift
- External validation

## Key Principle

High-performing AI models depend on appropriate, representative, and well-documented data.

Medical AI data should therefore be considered in relation to:

- Population
- Clinical setting
- Data provenance
- Data quality
- Privacy
- Bias
- Generalizability
