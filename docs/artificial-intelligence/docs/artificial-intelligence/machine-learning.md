# Machine Learning

## Definition

Machine Learning (ML) is a branch of artificial intelligence in which computational models learn patterns from data to perform tasks such as prediction, classification, estimation, or decision support.

## Major Types

### Supervised Learning

Learning from labeled examples.

Examples:

- Classification
- Regression
- Risk prediction

### Unsupervised Learning

Finding patterns or structures without predefined labels.

Examples:

- Clustering
- Dimensionality reduction

### Reinforcement Learning

Learning through interactions with an environment using feedback or rewards.

## Medical Applications

Machine learning can be applied to:

- Disease prediction
- Risk stratification
- Medical imaging
- Patient monitoring
- Clinical decision support
- Biomedical research
