## 2. Source Scope

The source describes a proposed end-to-end governance and auditability sequence for Clinical Decision Support (CDS) software.

The framework covers:

1. Jurisprudential Grounding
2. Pre-Deployment Safety Validation
3. Algorithmic Transparency and Attestation
4. Interaction and Physician Oversight Thresholds
5. Surveillance, Drift and Circuit Breakers
6. Medical Reference and Global Safety Accord Harmonization

The source also addresses empirical validation, explainability, cryptographic provenance, physician oversight, longitudinal monitoring, and fallback mechanisms.

## 3. Primary Framework

The source identifies the following JPAIS-MED-REF sequence:

### J — Jurisprudential Grounding

The source describes legal and regulatory grounding for clinical AI systems, including device classification, liability boundaries, and data protection considerations.

### P — Pre-Deployment Safety Validation

The source describes:

* demographic and geographic fairness evaluation
* external multi-center benchmarking
* adversarial stress testing
* out-of-distribution detection
* Healthcare Failure Mode and Effect Analysis
* prospective shadow-mode validation

### A — Algorithmic Transparency and Attestation

The source describes:

* machine-readable model cards
* local SHAP explanations
* Grad-CAM visual explanations
* signed model manifests
* SHA-256 binary hashes
* tamper-evident audit ledgers
* hardware-backed key protection

### I — Interaction and Physician Oversight

The source proposes three operational autonomy tiers:

* Tier 1: Informative / Low Risk
* Tier 2: Collaborative / High Risk
* Tier 3: Autonomous Execution / Critical Risk

The source also discusses structured overrides and cognitive-friction mechanisms.

### S — Surveillance, Drift and Circuit Breakers

The source describes:

* Population Stability Index monitoring
* Kullback-Leibler divergence
* Clinician Override Rate monitoring
* automated model suspension
* deterministic fallback using HL7 CQL rules

### MED-REF — Medical Reference and Global Harmonization

The source describes alignment with clinical data standards and international AI/medical-device governance references.
